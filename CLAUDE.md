# CLAUDE.md - ExitMap

## Forma de trabajo: Spec-Driven Development

## Proyecto
Es una aplicación de escritorio para windows/linux que permite
analizar tu correo y obtener los servicios en los cuales estás registrado,
que relación tienes con ellos, que puedo eliminar, revocar o solicitar
que eliminen.

## Estilo
- Código en inglés, archivos de la carpeta `docs/` en español. Readme en inglés

## Reglas
- Lee docs/constitution.md y la spec activa antes de tocar código.
- No añadas funcionalidad que no esté en la spec.
- Si la spec es ambigua o contradice el plan, pregunta.
- Si un cambio afecta a los requisitos, propón primero el cambio en `spec.md`.
- No modifiques archivos dentro de `specs/` salvo petición explícita.

## Al terminar cualquier tarea

- Ejecuta los test y comprueba que todos pasen.
